## Changes per requirement

1. **Experiment vs other-calculations distinction.** LTPT symbols are now
   LARGE FILLED black circles (`ms=8.5`, `mfc='k'`, `zorder=12`) on all four
   panels — forces *and* oil-flow stations. Published-calc symbols stay small
   (`ms=4.5-6`) open gray. The reader tells experiment from CFD instantly by
   size+fill.

2. **2x2 layout.** Recast from 2-row/6-col to a clean 2x2:
   `[0,0] c_l | [0,1] c_d(log)` (top), `[1,0] c_m(c/4) | [1,1] combined
   separation+reattachment` (bottom). Drag stays log; the station panel keeps
   an x/c y-axis (0.28–1.05) with both bands on one axis, distinguished by
   trend and by direct in-panel text labels ("laminar separation" lower band,
   "turbulent reattachment" upper band). Top-row x tick labels suppressed
   (shared Re axis by column).

3. **alpha=4–6deg bracket pairs made self-explanatory.** The bare vertical
   lines are now CAPPED range bars (matplotlib `errorbar`, `capsize=5`)
   spanning the alpha=4 and alpha=6 values, with the small per-model end
   markers retained. A single legend entry reads
   "alpha=4–6deg bracket (no alpha=5 station datum)". Cole–Mueller at 1e5 and
   Ghimire+ variants at 3e5, both x_sep and x_R.

4. **Legend repositioned.** Now a figure-level legend BELOW the axes
   (`loc='upper center'`, `bbox_to_anchor=(0.5, 0.085)`), and the PDF/PNG are
   saved with `bbox_inches='tight'` + `bbox_extra_artists=(leg,)` so the
   canvas expands to include it. It sits below the bottom-row x-axis labels
   and overlaps nothing. `tight_layout` (which warned before) is removed.

5. **"Missing" LTPT circles on separation/reattachment — resolved + finding.**
   They were never missing data: the TM-4062 **Table III oil-flow** sep/reattach
   at alpha=5 is tabulated for **Re=1e5, 2e5, 3e5 only** (the `OIL` dict). At
   6e4 and 4.6e5 there is no oil-flow closure datum at alpha=5 — that is a
   genuine source limitation, not an omission. The circles that *do* exist were
   small, open (`mfc='none'`), and at 1e5 overlapped the Cole–Mueller bracket
   square, so they read as invisible. They are now large filled black and pop
   clearly. No data invented.

## Addendum (individual LTPT run points instead of mean+errorbar)

The old `EXP`/`EXP_ERR` was a single nearest-alpha=5 reading per Re plus an
*assumed* uniform scatter bar — not a set of individual repeat points. That
errorbar is removed. Each individual Table B1 run reading that was actually
hand-read from the scan is now plotted as its own filled black circle
(`EXP_CL`/`EXP_CD`/`EXP_CM`).

**Coverage of what is digitized in the repo** (source: the provenance
docstring of `paper/repro/cfd/regen_resweep_table.py`, hand-read from the
TM-4062 scan):

- **c_l:** 6e4 {.838}; 1e5 {.873}; 2e5 {.891, .895, .894, .897}
  (runs 9/10/13 at a=5.00/5.03/5.06/5.06); 3e5 {.901}; 4.6e5 {.914}.
- **c_d:** 6e4 {.0439}; 1e5 {.0237, .0240} (runs 15/16); 2e5 {.0137, .0138,
  .0139}; 3e5 {.0114}; 4.6e5 {.0093}.
- **c_m:** one value per Re (no per-run repeats transcribed).

So multiple circles appear where repeats were read (2e5 c_l/c_d, 1e5 c_d);
elsewhere a single circle. At 2e5 the four c_l readings agree to within 0.006
and render visually coincident — honest, since the runs agree.

**Not fabricated / would need digitizing.** The repo does NOT contain a
complete per-run digitization of TM-4062 Table B1. Each condition actually had
multiple runs (6e4 runs 27/28; 1e5 15/16; 2e5 9/10/13; 3e5 3/4/5; 4.6e5 20),
but only the readings above were transcribed. A complete individual-point set
would require re-reading **TM-4062 Table B1** from the scanned PDF
(`mcghee_1988`): every run row at each tabulated alpha near 5deg, all of
c_l / c_d / c_m. Also documented in prose but NOT plotted (different alpha, not
alpha=5): the 6e4 bistable lift collapse to c_l=.639 at a=5.51, and the a=4.00
repeat triple .643/.697/.721. These belong to a bistability/hysteresis
discussion, not the alpha=5 comparison, so they were left out.
