## Summary

The load-bearing physics is in good shape: every unit convention I audited in
the committed CFD generators is on the ONBOARDING §5 canon (velocity /M,
ν = M/Re for χ and Re_Ω, U-normalized 1/Re where θ/Cf need it), the
flat-plate χ fix is correctly scoped, and three output cross-checks (NLF
transition rows, Tu→χ∞ table, resweep-table SA-AI/LTPT columns) reproduce the
tex numbers digit-for-digit. The package's problem is **certification drift**:
the repro suite and README still describe the retired v2 gate-kernel paper.
`regenerate_cfd.py` cannot pass (it runs a script renamed away at f405585),
`regenerate_all.py` regenerates four figures/floats that were dropped from the

`constants_report.py` green-stamps "All 16 canonical constants match the paper

c_ν,ai = 1/12 where the paper says 1/6). One genuine reproducibility defect in
a committed table: the e⁹ column of tab:eppresweep at 60k/460k cannot be
produced by its cited script. And the stale-duplicate hazard that caused the
flat-plate near-miss (pass 37 minor 3) still exists for five more scripts:
`paper/regen_eppler_v2.py` et al. are diverged v2-era copies of the repro
canon, and ONBOARDING §5 still names them as the generators.

## Style findings

1. **Silent-skip failure modes in committed-figure generators** (the pattern
   the standing instruction flags): `regen_flatplate_flow360.py:171–172`
   (missing case → `print("missing"); continue` → partial 5-row figure, exit
   0 → PASS in the suite; line 269 then KeyErrors only if the FIRST case is
   the missing one); `regen_epp_resweep_suite.py:90,109,137` (broad
   `except Exception → continue` around probe/chi/surface extraction — a
   units or field-name regression would just thin the figure);
   `regen_chi_sheets.py:214,223` (FileNotFoundError → "SKIP (case
   incomplete)"); `regen_resweep_table.py` (xfoil absent → NaN LaTeX row,
   exit 0). Recommend one shared convention: every figure/table generator
   counts its expected panels/rows and exits nonzero on shortfall (an
   `assert n_drawn == n_expected` epilogue), with opt-out only via an
   explicit `SAAI_ALLOW_PARTIAL=1`.
2. **Sphere-kernel constants are restated in four places with no shared
   source**: `analytic/fig04_shapefactor.py:34–52` (C_NU_AI=1/6,
   K_ANCHOR=0.712, REOM_*), `driver/saai_env.py:53–59` (_SPHERE),
   `analytic/fig02_onset_graze.py:24` (CEIL/A/B — deliberate per the
   "NEVER refit" note, but still a restatement), and the test CANON. The
   repro `lib/` — advertised as "the model kernel" (README l. 12) — still
   holds only the retired v2 constants. Until lib is migrated, at least make
   fig04 and saai_env import from one module so 0.712 cannot fork. Also
   fig04_shapefactor.py:45 comment says "k = 0.708 at c_nu,ai = 1/6"
   directly above `K_ANCHOR = 0.712` — the 0.708 is the superseded
   short-domain value its own comment warns about; fix the digit.
3. **Committed junk in `analytic/`**: 11 tracked `__pycache__/*.pyc` files,
   `fig01_indicator_plane_q4.py.bak`, `texput.log` (a stray LaTeX crash log),
   4 `results_lambda_v_*.txt` scan outputs, and the 42-file `figs_explore/`
   scratch directory (pngs/npys/jsons of exploration outputs), plus the stray
   XFOIL BL dump `cfd/:00.bl`. None are inputs to any script I could find.
   git rm + extend .gitignore (`__pycache__/`, `*.pyc`, `*.bak`).
4. **`regen_flatplate_flow360.py:297–300` dead code**: `ref_handles`
   (AGS-onset + S-S-band legend proxies) is built and never passed to
   `ax_cf.legend(...)` at l. 301, so those two entries never reach the
   committed figure's legend (the caption carries the identification, so this
   is dead code rather than a figure bug — but either pass
   `handles=h+ref_handles` or delete the block). Same file, ll. 314–345:
   two separate `__main__` blocks straddling late function defs — `main()`
   always regenerates the figure even when only `ONSET_DIAG=1` diagnostics
   are wanted; fold into one entry point. And l. 332: `for lev in (1.0, 7.1)`
   restates c_v1 as a literal two hundred lines after importing `C_V1` with
   the comment "import, never restate" (l. 20) — use the import, since the
   quoted AGS numbers are defined by this threshold.
5. **`analytic/_saai.py:15` `os.chdir(PAPER)` at import time** — a hidden
   global side effect that every analytic script inherits (it is why relative
   `data/...` opens work); it makes the scripts non-composable and is the
   kind of thing that breaks the next runpy/pytest embedding. Prefer
   PAPER-anchored absolute paths (the cfd scripts already do this).
6. **`cfd/regen_eppler_v2.py` carries live v2-kernel machinery inside the
