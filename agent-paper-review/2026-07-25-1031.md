## New major comments

1. **"no SA-BCM result at this condition is available in the open
   literature" (fig:nlfaft caption, l. ~1439) is contradicted by a
   paper in the author's own `references/` directory.**
   `references/tarsia2025.pdf` (Tarsia Morisco & Alauzet, "Assessment
   of Spalart-Allmaras One-equation BCM Transitional Model using
   anisotropic metric-based mesh adaptation") runs SA-BCM on the
   NLF-0416 workshop case at Re=4×10⁶, Tu₁=0.15, M=0.1 — the same
   benchmark, albeit at a single incidence (AoA=0°, Figs. 6–11) and
   M=0.1 vs the workshop's 0.2. The blanket sentence is refutable as
   written; it survives only as "no published SA-BCM *α-sweep* at
   this condition" (optionally citing Tarsia for the α=0° point —
   which could even be placed on the figure at cl≈0.4–0.5). The file
   is not in the bib; either cite it or scope the claim.

2. **The main-text "overpredicts the matched-lift drag by ∼45%"
   (l. ~1862) is stale against the table cell this commit upgraded.**
   0.0195/0.0138 → **+41%**; the ∼45% derives from the superseded
   figure-read 0.0200. In the same sentence block, "The comparison is
   read from the cited sources' figures … so it supports
   one-significant-figure conclusions only" is now half-stale too:
   the two polar cells are vector-exact matched-$c_l$ interpolations
   (as the caption correctly says), no longer figure-read with
   read-off error. One sentence retouch fixes both ("∼40%" or "+41%",
   and scope the read-off caveat to the bubble stations and $c_l$).

## New minor comments

1. **Committed-data provenance error**: the `condition` field of
   `data/lmbcm_eppler387_digitized.json` says "incompressible RANS
   (ANSYS Fluent)" — the source used **OpenFOAM (γ–Re_θ) and SU2
   (SA-BC)**; Fluent appears nowhere in it. The paper's table and
   captions are right; the JSON's own provenance line is wrong and
   will mislead the next reuse. (The `notes` field is otherwise
   exemplary.)

2. **Figure legend "(Denison et al.)" — single-author paper.** The
   tex caption cites "Denison~\cite{…}" correctly; the in-figure
   legend of `nlf_aft_transition.pdf` (from
   `regen_nlf_aft_comparison.py`) adds a wrong "et al.". Same class
   as the caption/legend consistency items of earlier passes.

3. **Matplotlib legend rendering in the touched figures**: (a) both
   new legend entries render a literal double hyphen — "γ--Re_θ" —
   because matplotlib does not ligate `--`; use an en-dash character
   or a math minus. (b) Pre-existing but now conspicuous in the
   regenerated NLF legend: the SA-AI entries render "L0oL2 by size"
   — the label string " (L0$\to$L2 by size)" is a *non-raw* Python
   string, so `\t` is a TAB character and the mathtext sees `$<tab>o$`;
   use a raw string or `$\\to$`. Both are one-line script fixes plus
   a regen.

4. **"one-significant-" line-break hyphen** (l. 1858) renders
   "one-significant- figure" with a spurious space in the PDF (TeX
   treats the newline after the hyphen as a space). End the line with
   `%` or rejoin. Pre-existing (bece4a7) but sits in the paragraph
   major 2 retouches anyway.

5. **Denison-condition disclosure**: the fig:nlfaft caption states
   OVERFLOW/fine grid but not that the workshop case is **M=0.2,
   Tu=0.15%** while every other element of the figure (experiment,
   AFT, XFOIL, SA-AI) is at the paper's M=0.1 framing. Transition-vs-
   $c_l$ makes the Mach difference nearly immaterial, which is exactly
   why a six-word parenthetical ("workshop condition: $M=0.2$,
   $Tu=0.15\%$") is cheap insurance against a referee spotting it
   before the caption does.

6. **Log-accuracy nits (no tex impact)**: the commit message says the
   digitization was verified "by overlaying replots on the source
   pages" — the committed check PNGs are side-by-side original/replot
   panels, not overlays (they do the job); and "includes
   width=\textwidth" was already true before the commit (the tex mesh
   includes are untouched; only the PDFs' canvas changed). The
   RESPONSES claim "both inside the old error bars" is exact for
   SA-BC but boundary-exact for LM (0.0195 = 0.0200 − 0.0005).
