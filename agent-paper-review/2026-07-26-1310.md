## Bug verification

1. **Units, from the case configs.** Both canons' `Flow360.json` set
   `modifiedTurbulentViscosityRatio = 2.2766947724125476e-06` at Tu=0.04%
   (= χ_∞·fSlow with fSlow=0.01, per `flow360/run_flatplate_ags.py`), and
   `flow360_fr/flatplate_sphere_inventory.json` records
   `chi_inf = 2.2767e-4`, `muRef = 1.0e-7`. So ν in solver (a_∞·L) units is
   M/Re = 1e-7 — the same convention the other regen scripts already use
   correctly (`regen_eppler_v2.py`: `NU = 5e-7 # = muRef = M/Re` at Re=200k;
   `regen_nlf_v2.py`: 2.5e-8 = 0.1/4e6; `regen_naca_v2.py`: 2e-7 = 0.1/5e5).
   The flat-plate script's `chi = nuhat/1e-6` was the lone offender (its
   comment "nu = 1/Re" was the error). CONFIRMED.
2. **From the raw output.** Sampling `flow360_fv1/flatplate_sphere_Tu0040/volume.pvtu`
   at the inlet and just above the BL (wd 0.05–0.15) gives nuHat = 2.277e-11,
   i.e. χ_∞ = 2.277e-4 with ν=1e-7 — the intended Mack seed exactly. With the
   script's 1e-6 it displays as 2.28e-5, a decade low. Tu=0.16 likewise:
   6.342e-10 → χ_∞ = 6.342e-3 = intended. CONFIRMED, and stronger than 1253
   states: the seed is not merely "right at" the intended value, it is exact.
3. **Not a one-line fix — and the revising agent got this right.** `NU` in
   that script also serves as 1/Re in `Re_theta = theta/NU`,
   `Cf = 2*NU*u'/wd`, `Re_unit = 1/NU` (AGS marker x-placement), and
   `ZG/NU` (contour y-axis). Those all need 1e-6 (u is already /MACH, so the
   U-normalized viscosity scale is 1/Re). 1253's prescribed fix
   ("`NU = 1.0e-7`", repeated in its Notes) would have made Re_θ 10× high,
   Cf 10× low, and shifted the AGS markers 10× in x. The applied fix
   (`NU_CHI = 0.1*NU`, used only in `extract_volume`'s χ) is the correct
   minimal change; `onset_vs_ags()` is fixed transitively. Verified both
   copies (`paper/` and `paper/repro/cfd/`) carry the same two-hunk diff.
4. **Affected panels, confirmed by rerun:** the log₁₀χ contour labels and the
